# KanaBuddy

Simple static website for practicing Japanese Kana.

Practice on the:
- [KanaBuddy Website](https://kanabuddy.org)
- [KanaBuddy Android App](https://play.google.com/store/apps/details?id=com.btemplep.kanabuddy)


## Development

KanaBuddy is plain HTML, CSS, and JavaScript with no build step, frameworks, or
Node installs required.

To work on it locally:

1. Clone the repository.
2. Open `src/index.html` in your browser.

The styled Japanese fonts are self-hosted (subset to just the kana and basic
Latin glyphs the app uses), so no internet connection is required.

### Fonts

The styled fonts live in `src/fonts/` as kana-subset `.woff2` files and are
declared in `src/css/fonts.css`. Both are generated by a script, so neither
should be edited by hand.

To regenerate them (for example after changing the font list in
`src/js/kana-data.js`):

```console
python3 scripts/fetch-fonts.py
```

The script asks the Google Fonts API for each family subset to only the glyphs
KanaBuddy renders, saves the `.woff2` files, and rewrites `src/css/fonts.css`.
It only runs at development time; the shipped site has no runtime dependency on
Google Fonts. The fonts are licensed under the SIL Open Font License.

### Versioning

The app version lives in a single place: `src/js/version.js`.

```javascript
const APP_VERSION = "0.1.0";
```

When cutting a release, update `APP_VERSION` and add a matching entry to
`CHANGELOG.md`. The version is displayed in the site footer automatically (it
links to the changelog), so there is only one value to edit.

### Testing

Run tests:

```console
npm test
```


## Android app

The repository also contains an Android app (in `android/`) that wraps the same
site in a WebView, so the web app in `src/` is the single source of truth for
both.

At build time, a Gradle `syncWebAssets` task copies `src/` into the app's
generated assets, and the app serves those files locally with
`WebViewAssetLoader`. Because the fonts are self-hosted, the app needs no
network access and declares no `INTERNET` permission.

To build it:

```console
cd android
./gradlew assembleDebug
```

Notes:

- Edit the site in `src/` only. The copy under the app's generated assets
  directory is regenerated on every build and is not committed.
- The app version is read from `src/js/version.js`: `versionName` matches
  `APP_VERSION`, and `versionCode` is derived from it (e.g. `0.5.0` -> `500`),
  so a release bump is still a single edit.
